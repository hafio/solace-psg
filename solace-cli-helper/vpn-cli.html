This scripts is meant to process show current-config message-vpn * outputs to allow you to run it again (usually in context of migration). It does the following: - Provision all VPN bridges in "shutdown" state - Removes all "replication" configuration - Adds a shutdown line for "default" username to allow changes - Adds shutdown lines for service listen-port to allow changes
