# Solace Parser

Parses output from Solace CLI `show current-config all` and `cli-diagnostics.txt` from Solace Gather Diagnostics.

## Options

Specify the following URL Parameters for certain features:

| Parameter | Value | Description |
| - | - | - |
| `ignoreHostnameMatch` | `true` | Hostname in both files do not need to match. Only use this if really required. |
