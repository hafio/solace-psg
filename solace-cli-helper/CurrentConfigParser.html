This scripts is meant to process show current-config all|message-vpn * outputs to allow you to run it again (usually in context of migration). It does the following: - Separates System (e.g. system, scaling, interface, hardware, broker wide services) configuration - Separates Broker wide username, authentication, and authorization configuration - Separates each message vpn's configuration - highlights sections (VPN, Client Profile, Message Spool, Endpoints, ACL Profile, Client Username, Bridge, and JNDI) - Separates "redundancy" configuration - Separates broker & message vpn "replication" configuration - Changes all VPN bridges to be provisioned in "shutdown" state - Adds a shutdown line for "default" username in each vpn to allow changes - Adds shutdown lines for service listen-port to allow changes
  • Message VPN
  • Client Profile
  • Message Spool
  • Endpoints
  • ACL Profile
  • Client Username
  • Bridge
  • JNDI
