# Solace Syslog Table Convertor

This project helps convert the list of Solace Syslog Events into a table which can be pasted into Excel for easier processing/filtering.

# Instructions

1. Save the [Solace Syslog Events](https://docs.solace.com/Admin-Ref/Solace-PubSub-Event-Reference/event_ref_boiler.html) page locally.
2. Copy the content in `SolaceSyslogTable.html` without the `<html>` tags into the locally saved html page.
  - You can paste it at the start or the end of the file (within the `<html>` tags)
3. Open the modified file
4. Navigate to the `Create Table` button
5. Click `Create Table` button and the syslog table should be generated.
6. Either use `Copy Table` button or manually copy the table to Excel for further uses.
